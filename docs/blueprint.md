# **App Name**: Tesla Demo Tracker

## Core Features:

- Multi-Store Selection: Allow users to select from predefined Tesla store locations.
- Vehicle Fleet Display: Display vehicles with details such as model, VIN, battery level, and status.
- Demo Drive Checkout: Enable advisors to checkout vehicles for demo drives, setting duration and purpose.
- Demo Drive Check-in: Enable advisors to check-in vehicles after demo drives, capturing feedback and issues.
- Real-time Data Synchronization: Firebase Realtime Database to sync changes across multiple devices instantly.
- Issue Detection: Use a tool for AI-powered detection of issue keywords in user feedback to improve issue reporting accuracy.
- Role-Based Access Control: Implement advisor and manager roles with password protection for elevated access.

## Style Guidelines:

- Primary color: Tesla Red (#DC2626) to reflect the brand's identity.
- Background color: Dark gray (#1F2937) for a modern, high-tech feel.
- Accent color: Blue (#2563EB) for interactive elements and highlights.
- Body and headline font: 'Poppins' sans-serif font for a contemporary, precise feel.
- Use modern, minimalist icons to represent vehicle status and actions.
- Responsive grid layout adapting to different screen sizes for optimal viewing experience on all devices.
- Subtle animations for transitions and feedback to enhance user experience.
